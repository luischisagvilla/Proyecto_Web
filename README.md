### 📖 Descripción del sitio web
**JuegosESPE** es un sitio web desarrollado con el propósito de brindar información sobre tres videojuegos que formarán parte del evento **GamerFest de la ESPE**. 

La página permite a los usuarios conocer información y detalles relevantes de cada uno de los juegos presentados.

### 🛠️ Tecnologías utilizadas
Para el desarrollo del proyecto se utilizaron las siguientes tecnologías y herramientas:

- **HTML5:** Para la estructura y organización del contenido de las páginas web.
- **CSS3:** Para el diseño y personalización de los estilos visuales.
- **Bootstrap:** Para facilitar el diseño y la creación de una interfaz adaptable.
- **Git:** Para el control de versiones del proyecto.
- **GitHub:** Para alojar el repositorio y facilitar el trabajo colaborativo.
